# Security Policy

## Supported versions

Security fixes are provided for the latest released version and the `main`
branch. Older releases do not receive backported fixes.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub
issues, discussions, or pull requests.

Report them preferably through GitHub private vulnerability reporting:
open the repository's
[Security advisories page](https://github.com/h2lab/pyGdbToolkit/security/advisories)
and click **Report a vulnerability**. This keeps the report private between
you and the maintainers until a fix is available.

If you cannot use GitHub private reporting, contact the H2Lab team by email at
[secretariat@h2lab.org](mailto:secretariat@h2lab.org). Use this channel only
as a fallback.

In your report, include as much of the following as possible:

- the affected component (`pyGdbToolkit`, `pyGdbServer`, `pyGdbClient`, LLM
  integration, …) and version or commit,
- the type of issue and its potential impact,
- step-by-step instructions or a proof of concept to reproduce it,
- any suggested mitigation or fix.

## What to expect

We will acknowledge your report, keep you informed of the progress of the
analysis and fix, and credit you in the advisory unless you prefer to remain
anonymous. Please give us a reasonable time to release a fix before any public
disclosure.
